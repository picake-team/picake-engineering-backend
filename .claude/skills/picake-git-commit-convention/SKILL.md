# 커밋 메시지 규칙

이 레포(`picake-engineering-backend`)는 backend 전용입니다. 웹 레포는 `[WEB-USER]`/`[WEB-SELLER]`/`[WEB-ADMIN]`/`[COMMON]`을 씁니다.

## 형식

```
[접두사]: 내용
```

- 접두사는 아래 2개 중 변경 범위에 맞는 것 하나를 사용합니다.
  - `[BE]`
  - `[COMMON]`
- 내용(본문)은 한국어로 작성합니다.

## 접두사 선택 기준

| 접두사     | 대상                                        |
| ---------- | ------------------------------------------- |
| `[BE]`     | `apps/backend` 변경                         |
| `[COMMON]` | 루트 설정, 워크플로우, 문서 등 앱 밖의 변경 |

`git status`로 변경된 파일이 앱(`apps/backend`)인지 그 밖의 영역인지 먼저 확인한 뒤 접두사를 정합니다.

## 예시

```
[BE]: 인증 토큰 만료 처리 수정
[COMMON]: ESLint 설정 업데이트
```

## 주의

- 사용자가 명시적으로 요청하지 않으면 커밋하지 않습니다.
